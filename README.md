# Global Automotive Sales Performance Dashboard

An interactive Power BI dashboard analyzing global automotive retail sales data (2003–2005) to track profitability, regional customer demand, and product performance metrics.

## 📊 Dashboard Preview
![Automotive Sales Dashboard][global-sales-analytics-dashboard]

## 🎯 Project Overview
This project focuses on extracting actionable business intelligence from a multi-year automotive retail dataset. The dashboard provides stakeholders with clear insights into revenue growth, profit margin fluctuations, and product inventory trends across global markets.

## 💡 Key Features & Insights
* **Profitability Mapping:** Tracked $3.83M total profit with an overall profit margin of 39.84% across global operations.
* **Product Line Performance:** Visualized quantity ordered across key categories like Classic Cars (the top revenue driver), Vintage Cars, Motorcycles, and Trucks.
* **Geographic Demand:** Interactive map visualization detailing customer concentrations across North America, Europe, and Africa.
* **Top & Bottom Performers:** Isolated top-selling items (e.g., 1992 Ferrari 360 Spider red) and underperforming assets to assist inventory management decisions.

## 🛠️ Tools Used
* **Business Intelligence:** Power BI Desktop
* **Data Sources:** Multi-year vehicle retail sales dataset (2003–2005)
* **Visualizations:** Treemaps, Bar Charts, KPI Cards, Map Visuals, Pie Charts
