Customer Churn Analysis Dashboard

📊 Overview
This interactive dashboard tracks key performance indicators (KPIs) and behavioral trends driving customer attrition.

⚙️ Tech Stack & Tools

• BI Platform: Power BI
• Data Sources: CSV / SQL Database
• Languages: DAX (Data Analysis Expressions) & Power Query (M)

📈 Key Metrics

• Total Customers: 7K
• Churn Rate: 26.54% (Retention Rate: 73.46%)
• Historical Revenue Lost: $2.9M ($139.13K monthly)
• Average Tenure: 32 Months

🔍 Core Insights

• Onboarding Risk: 47.44% of churn occurs within the first 12 months.
• Contract Vulnerability: Month-to-month contracts experience a 42.71% churn rate.
• High-Risk Segments: Fiber Optic internet users (41.89%) and Electronic Check payment users (45.29%) exhibit the highest attrition.

🛠️ Visualizations Included

• Monthly Charges vs. Tenure: Billed amounts categorized by customer lifespan and active status.
• Segment Analysis: Churn distribution across contract terms, payment methods, and internet services.
• Interactive Filters: Global slicing by Tenure Group and Dependents.
